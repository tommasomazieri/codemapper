# codemapper API — Symbol Queries

> **Status: stub — not yet documented.**

## Planned endpoints

- `GET /symbol/{name}` — Definition location(s) for a named symbol across the entire indexed repo
- `GET /usages/{name}` — All usage locations for a symbol (lines where it is referenced as a Name or Attribute node)
- `GET /imports/{module}` — Files that import a given module
- `GET /search?q=` — Case-insensitive fuzzy symbol search across all indexed symbol names

Full documentation coming in the next iteration.
